# MIZA GALAXY — Teacher Module

برنامج إدارة حلقات القرآن الكريم — وحدة المعلم

## المميزات
- إدارة الطلاب والجلسات بشكل كامل بدون إنترنت.
- تتبع الأخطاء والتنبيهات أثناء التسميع.
- نظام خرائط حرارية (Heatmap) لتحديد نقاط الضعف.
- لوحة تحكم ذكية وإحصائيات تقدم الطلاب.

## التشغيل

هذا التطبيق مصمم للعمل كبرنامج سطح مكتب باستخدام Electron.

### التشغيل للتطوير (Electron)
```bash
npm install
# في نافذة أولى:
npm run dev
# في نافذة ثانية:
npm start
```

*ملاحظة: عند تشغيل `npm run dev` في المتصفح مباشرة، سيعمل التطبيق في "وضع التجربة" (Web Fallback) ببيانات وهمية لأن المتصفح لا يدعم الوصول لقاعدة البيانات المحلية.*

## البناء
```bash
npm run build
```
